# Fryn Desktop v1.3.0

## Identidade visual

- substitui a marca d'água `opencode` da tela inicial pela marca Fryn;
- remove o selo `DEV` do instalador distribuído aos usuários;
- usa o canal de produção e os ícones do Fryn no build do Windows;
- oculta o convite para conectar provedores externos quando o Fryn já está ativo.

## Modos de IA

- mantém o seletor de modos Fryn nas duas versões da caixa de mensagem;
- exibe o modo ativo e permite alternar entre Code, Fast, Expert, Plan e Vision.
